# 真实人生档案 · PSID 54 年家庭追踪

从 PSID（美国收入动态面板研究）1969-2023 追踪数据中，抽取真实家庭的 54 年人生。

## 玩法

- **随机抽取一户**（1,832 个追踪 ≥5 wave 的家族）
- **按人生剧本浏览**：人生赢家(376)/逆袭翻身(537)/财富跌落(280)/稳步上升(341)/平凡一生(298)
- **档案卡**：时间线（每 wave：收入/净资产/住房/婚姻/家庭人数/州 + 当年美元与 2024 折算）+ 美国年代背景（滞胀/储贷危机/互联网泡沫/金融危机/疫情）+ 动态中文解读

## 数据

- 源：PSID Family Files 1969/1979/1989/1999/2009/2019/2023（原始 + 解析，见 `../人生账本模拟器/` 的 psid_vparse.py / psid_merge7.py）
- **主脉匹配**：按 1968 血脉 ID（id1968）跨年关联；每 wave 贪心选「户主年龄延续最平滑」的一户（换代时自然跳到下一代）
- **通胀折算**：BLS CPI-U 年度均值（FRED CPIAUCSL），统一折到 2024 美元（1969×8.55 / 1979×4.32 / 1989×2.53 / 1999×1.88 / 2009×1.46 / 2019×1.23 / 2023×1.03）
- 净资产（含房产）1989 起有（PSID 财富模块 1984 年才启动）；1969/1979 无财富数据
- 分位对比：按当年 PSID 样本 wealth 分位（P10/25/50/75/90）插值

## v2《起点与终点》· 流动性分析（2026-08-27）

- 需求：看起点家庭分布 → 选起点 → 看 54 年后的结果（"开头好结局差 / 开头差结局好"）
- 数据：1,620 个全程家族（1969 收入 + 2023 财富齐全）psid_mobility.py → mobility.json（360KB）
- 视图：
  1. **起点分布**：1969 收入五等分卡片（收入区间/租房率/家庭规模），点选起点
  2. **命运统计**：升/平/降比例 + 终点财富中位数（当时+2024折算）
  3. **5×5 流动性矩阵**：起点等分 × 终点等分（热力），点格子看具体家庭
  4. **反转人生**：高开低走（起点 Q4/Q5→终点 Q0/Q1，8户）vs 低开高走（Q0/Q1→Q4/Q5，8户）
  5. 样本点击 → 跳转 v1 档案（?id= 直链）
- 关键发现：固化率 32%（随机 20%）；Q0 升 84% vs Q4 跌 43%；终点财富中位 $80k（Q0）vs $559k（Q4）
- 文件：起点与终点.html（373KB）+ template_mobility.html + psid_mobility.py + build_mobility.py
- v1 已支持 ?id=xxx 直链

## v3《1969·美国人生》· 历史驱动模拟（2026-08-27）

- 需求：从真实起点（起点与终点的 Q0-Q4）出发，自己模拟人生做选择，看结果
- 历史参数：FRED 真实数据 → US_HIST.json（1969-2023 每年：通胀 CPI-U / 标普含股息（SPASTT01USM661N Q4）/ FHFA 房价 / 30年房贷利率 / 失业率）
  - 关键年份：1974 股市-31%、1981 房贷16.64%、2008 股市-40%/房价-7%、2020 失业8.1%
- 引擎：起点五等分（1969 真实中位收入起薪）→ 学历×职业 → 11 个历史决策节点（1972结婚/1975买房/1979投资/1981换房/1987入市/1995互联网/2000止盈/2005投资房/2008金融危机/2015配置/2020疫情）→ 2023 结算
- 结算：净资产（当年美元+2024折算）+ 超过同起点真实家庭 x%（mobility fams 对照）+ 4 节点反事实复盘 + 净资产曲线
- 文件：1969美国人生.html（40KB）+ template_us.html + annual_hist.py + build_us.py
- 踩坑：buyHouse const 重赋值 TypeError；replay 忘记按年份应用决策（重复应用）；diff 用了对象减数字（NaN）——均已修复
- 已验证剧本：Q0 蓝领存钱买房 → $2.27M/96%；Q3 个体经营 → $575k/71%，复盘"2005投资房vs不碰 -$7,002"（2008教训）、"2000止盈vs持有 +$422k"

## 死亡推断版（2026-08-27）

- 背景：PSID Mortality File（2023 版，含 NDI 死因）是 **Restricted Data**——申请需简历+研究计划+IRB+机构合同+虚拟数据飞地远程分析，不现实
- 替代方案（已上线）：**生命表推断**——1969-71 美国生命表（SSA/CDC 口径，男女分表）按原户主 1969 年龄插值 → 推断死亡年龄/年份区间（±7 年）
- 档案展示：「✝ 原户主 1969 年 53 岁，按 1969-71 美国生命表推断，约于 1984-1998 年间离世（享年约 68-82 岁）。此为统计推断，非死亡记录。」+ 原有"大概率已不在世"警示 + 换代徽章
- 数据：merged7.csv 加 sex_rp（1969=V1010/1979=V6463/1989+=sex_rp）；families.json 主脉带 sex
- 局限：死因（ICD）不可得（受限）；"已故配偶"编码（formats 18）在面板 marital 变量中未触发
- 待办：若用户以后有学术机构渠道可申请 Mortality File 拿精确死亡年份/死因

- 对外命名：原「人生账本」统称 **嚯嚯模拟人生**；「如果我是 TA」为待开发反事实模式（二者在 Pages 入口标为待定）。
